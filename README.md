# 🛒 E-commerce Sales Analysis Dashboard (Power BI)

This Power BI project analyzes the sales performance of an e-commerce business using key metrics and visuals to gain business insights and support data-driven decision-making.

## 📊 Project Overview

The main goal of this dashboard is to help the business understand:

- Sales trends over time
- Top-performing products
- Revenue by category and region
- Customer purchasing behavior
- Inventory and stock movement insights

## 🛠 Tools Used

- **Power BI** – For creating the interactive dashboard and visualizations
- **Excel / CSV** – Data cleaning and transformation (if used)
- **DAX** – For creating calculated columns and measures

## ✅ Key Insights

- 📈 Monthly revenue trends showed consistent growth in Q2
- 🏆 Electronics category brought the highest revenue share
- 🌍 South Region outperformed other regions in customer acquisition
- 📉 Certain products have low turnover – flagged for review

## 🔚 Conclusion

This dashboard offers a complete overview of sales performance and can be extended further by integrating customer segmentation or predictive models using Python or SQL.
